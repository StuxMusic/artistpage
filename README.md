# Artist Page

A clean and simple placeholder page for a Stux.Music artist who hasn't set up their page yet.

## Overview

This repository contains a lightweight HTML page shown in place of an artist's profile when they haven't set one up yet. It points visitors back to Stux.Music and gives the artist a way to claim their page.

## Features

- 📄 Simple, clean HTML structure
- ⚡ Lightweight and fast-loading
- 🎨 Ready to customize
- 📱 Responsive design
- 🚀 Deployed at [artistpage.stux.music](https://artistpage.stux.music)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/StuxMusic/artistpage.git
   ```

2. Open `index.html` in your browser or deploy to your hosting provider

## Customization

Edit the HTML files to:
- Update the message
- Add your branding and logo
- Customize colors and styling
- Include additional links

## Deployment

This project uses GitHub Pages and can be automatically deployed to your desired domain.

The live version is deployed at [artistpage.stux.music](https://artistpage.stux.music).
